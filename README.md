# Sentiment-Annotation
情感标注项目： 我构建了一个面向大学生创业项目的「多 Agent 协作式文本情感标注辅助系统」，解决了团队人工标注效率低、标准不统一、易出错的痛点。 系统采用多 Agent 协作架构：标注 Agent 负责根据项目定义的规则，自动对文本数据进行初标注；校验 Agent 通过长链推理逻辑，对比标注结果与标准库进行交叉验证，识别不一致标注；优化 Agent 则根据校验结果生成标注规则迭代建议，形成闭环优化。 目前已在团队的创业项目中落地使用，将单批次标注效率提升了 70%，人工校验成本降低了 60%，同时标注一致性准确率从 82% 提升至 95%，大幅缩短了项目的数据处理周期。
