# Sentiment-Annotation
情感标注项目： 我构建了一个面向大学生创业项目的「多 Agent 协作式文本情感标注辅助系统」，解决了团队人工标注效率低、标准不统一、易出错的痛点。 系统采用多 Agent 协作架构：标注 Agent 负责根据项目定义的规则，自动对文本数据进行初标注；校验 Agent 通过长链推理逻辑，对比标注结果与标准库进行交叉验证，识别不一致标注；优化 Agent 则根据校验结果生成标注规则迭代建议，形成闭环优化。 目前已在团队的创业项目中落地使用，将单批次标注效率提升了 70%，人工校验成本降低了 60%，同时标注一致性准确率从 82% 提升至 95%，大幅缩短了项目的数据处理周期。
多Agent协作式文本情感标注辅助系统使用说明书

一、项目概述
本系统面向大学生创业项目，解决人工情感标注效率低、标准不统一、易出错的痛点，采用“标注Agent+校验Agent+优化Agent”协同架构，实现文本情感（积极/消极/中性）自动标注、错误校验与规则闭环优化，基于Python原生开发，无需复杂依赖，适配校园各类文本标注场景。

二、核心技术与创新点
2.1 核心架构
1. 标注Agent：基于关键词匹配，自动完成文本初标注；
2. 校验Agent：通过长链推理，识别情感冲突与标注错误；
3. 优化Agent：收集错误案例，生成关键词库优化建议，实现闭环迭代。
2.2 创新点
1. 轻量化：Python原生开发，无复杂依赖，大学生可快速上手；
2. 闭环协作：三大Agent联动，兼顾效率与准确性；
3. 场景适配：关键词库可自定义，贴合校园创业项目需求。

三、环境要求与准备
3.1 环境要求
Python 3.8及以上，Windows/macOS/Linux均可；
无需安装第三方库，纯原生运行。
3.2 准备工作
1. 新建无中文、无空格的项目文件夹（建议命名：sentiment_annotation_system）；
2. 新建Python文件（命名：emotion_agent.py），复制完整代码并保存。

四、快速运行步骤（3步）
1. 打开终端：Windows用Win+R输入cmd/PowerShell，macOS/Linux打开终端；
2. 进入文件夹：输入命令 cd 你的项目文件夹路径（替换为实际路径）；
3. 运行系统：输入命令 python emotion_agent.py，查看输出结果。

五、核心功能使用
1. 标注Agent：运行系统后自动标注文本，输出positive/negative/neutral标签；
2. 校验Agent：自动校验标注结果，识别情感冲突与错误并提示；
3. 优化Agent：运行结束后输出关键词库优化建议，助力迭代。

六、自定义配置（简单操作）
1. 修改关键词库：打开代码找到RULES字典，添加/删除对应情感关键词，保存后重启系统；
2. 替换待标注文本：找到test_texts列表，替换为自身项目文本，保存后重启系统。


七、常见问题解决
1. 报错“python不是内部命令”：重新安装Python并勾选Add Python to PATH，或用Python完整路径运行；
2. 标注不准确：根据优化建议扩充关键词库；
3. 无输出/模块报错：重新复制完整代码，升级Python至3.8及以上。

八、项目成果
可将标注效率提升70%，人工校验成本降低60%，标注一致性准确率从82%提升至95%，适配大学生创业比赛、课程设计及实际项目使用。
